# tree-chat 界面设计

2026-10-15 使用 web-agent-collaboration 工作流，与 Claude 网页中实际显示的 **Sonnet 5.5 高** 进行一轮界面评审。评审只提供隔离测试截图、现有组件结构和 DSH 扩展接口约束；原始请求与完整回复保存在本机 `web-agent-handoff/tree-chat-ui/batches/01-review`，不随 Git 或安装包分发。

采用的建议：

- 去掉重复标题、口号、常驻说明、图例和编号面包屑；入口保留图标与可访问名称。
- 工具栏高 40px；节点只显示单行消息标题；根节点为圆点。
- 当前路径用连线颜色表示，当前聊天节点用左侧色条表示，选中节点用边框与外环表示。
- 底部详情区可折叠，消息可逐条展开；主操作文字为「继续」「分支」。
- ResizeObserver 根据真实侧栏宽度切换 168×40、188×44、200×44 节点；不以浏览器窗口宽度推测侧栏尺寸。
- 默认 90% 或 100% 缩放（全图能以至少 85% 显示时小幅调整以完整容纳），以可读文字和当前节点为中心；用户手动平移后保留其视野。低于 60% 缩放使用圆点概览。
- 端口视觉尺寸 6px、操作范围 20px，支持点击和拖动；拖动可落在目标卡片上。空白处放开取消，拒绝环路。
- 增加画布方向键导航及 Enter / Shift+Enter 操作。

样式限定在插件命名空间，继承 DSH 字体、颜色 token、原生 Sidebar tab 和分栏能力。无全局 reset，无第三方图编辑框架，不依赖宿主 DOM 结构。测试脚本对宿主原生分栏拖拽条的定位仅用于隔离 GUI 验证，不进入插件运行代码。

## 0.1.1 交互调整

依据用户反馈，默认以 `source.kind=user` 的真实输入生成可视卡片；`goal`、`user-approval` 等内部轮次使用视图投影折叠，原图节点、消息坐标及上下文不删除。单一自动续跑链归入前一条输入的继续位置；分叉不明确时保留原分叉点，可切换完整轮次视图进行精细编辑。详情区默认过滤内部提示文本，保留助手回复。

节点正文支持鼠标/触控拖动，4px 阈值区分点击和拖动，使用指针捕获，移动距离按缩放反算世界坐标。连线实时更新，松开后才提交坐标；Esc 或指针取消恢复起点。位置作为节点可选字段保存，兼容原 schema 1。拖动、自动排列及其撤销不改变上下文路径；并发新消息引起版本冲突时重新读取后重试布局保存。

## 0.1.2 节点导航

按用户反馈移除详情 dock，画布占满侧栏。点击正文跳到原生聊天消息；拖动正文只移动节点，屏蔽拖动结束产生的 click。端口负责起线及接线，正文不再作为接线目标。继续、分支、重命名、断开及删除放在悬停的「…」和右键菜单中；临时确认框只在操作时出现。

Host 用保留的消息 ID 解析目标会话的实际轮次，而非复用旧日志坐标；优先在当前枝定位，不存在时浏览来源会话。跳转不调用上下文派生接口。

DSH 0.2 未公开消息滚动接口。`navigation.js` 使用官方 Slot store 共享视图选择、公开 Session `loadThrough` 加载历史；最终读取 `data-conversation-content`、`data-chat-turn` 等语义标记滚动至消息。这是对早期“完全独立于宿主 DOM”设计的限定扩展，集中在适配器中做能力检测，不调用私有组件方法。新的跳转取消旧请求，防止快速点击后发生旧导航回跳；释放时取消等待并清理定位标记。

## 0.1.3 起点显示

根节点改为 88×30px 的「起点」圆角标签，正文和输出端口分开；沿用宿主卡片和文字颜色。缩小到概览时仍显示起点名称，用户自定义的根节点名称继续保留。点击跳到对话开头，正文可拖动，底部端口用于拉线。
