# tree-chat 1.0 设计与协作复核

日期：2026-10-19。

应维护者要求，通过 web-agent-collaboration 工作流与 Gemini 网页中实际显示的 **Argon** 协作。未确认独立推理档位，不推断具体档位。请求只提供公开仓库地址、公开数据接口和集合需求；未上传宿主内部源码或用户截图。

Argon 明确说明无法从网页工具读出 GitHub 仓库源码，因此本次是基于接口的功能设计与纯函数模块协作，**不属于对现有整个仓库的独立源码审核**。网页回复与 JavaScript 文件已完整取回；原始交接产物保存在维护者本机，不随发行包分发。

## 采纳的交互

- 集合只是显示代理，底层消息和 parent 路径不变。
- 选择至少两个相连节点，不能包含起点、跳过中间节点或让成员重叠。
- 使用命名、折叠/展开、取消、按内部边拆分；允许 Y 型组，保留全部出口。
- 拆分后少于两个节点的分量恢复普通节点。重复拆分可形成多个集合。
- 搜索临时展开匹配成员，拖动组平移成员；不自动把新聊天收入旧集合。
- 暂不增加嵌套集合、自动聚类、独立摘要、改变上下文的“压缩”或恢复手工拉线，避免混淆显示与模型上下文。

## 代码集成与修正

Argon 提供的集合核心文件直接作为 `src/core/groups.js` 的起点，主代理负责宿主适配和测试，并做了以下修正：

- 递归投影改为显式栈；拆分和删除修复改为邻接表遍历，避免深树栈溢出与反复全图扫描。
- 原生 binding 适配为实际 `{head}` 结构；组合内部轮次与集合的 owner 映射，保留隐藏内部节点上的分叉和空枝出口。
- 新集合 ID 由 UUID 生成，自动修复 ID 避免已有名称冲突，修复名称遵守长度限制。
- `group-state.js` 负责严格校验、应用编辑及旧图兼容；`groups.js` 保持纯函数，不读取宿主或网络。
- 权限继承单独放入 `host/permissions.js`，调用 DSH 原生 preset/sandbox/approval 服务，不复制原生权限实现。
- 展开折叠不占撤销历史；结构或名称修改可撤销；生成新消息时沿用既有的历史清空规则。

## 验证与边界

使用真实 DSH Session 验证完整上下文与工具配对；服务测试覆盖新旧分支、自定义权限、卸载目标的原生恢复和 Auto 拒绝路径；隔离 Web Host 验证集合的完整 GUI 交互。深树核心测试覆盖 12,000 节点，批量定位索引覆盖 5,000 次放置；这些是功能回归，不作为所有设备的性能保证。
