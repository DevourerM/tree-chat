# tree-chat 实现规划

目标运行时：本机 DeepSeek Harness 0.2.0-rc.2（build 04f392c）。

## 行为

- 页头智能体目录旁增加 tree-chat 入口，在原生 Sidebar tab 中展示纵向节点画布。
- 节点表示一个完整的用户交互轮次（包括工具调用及其结果），选中节点展示预览。
- 选择任意历史节点继续，只有需要新上下文时才建立可继续的原生 Session；后续轮次自动接入当前枝。
- 输入、输出端口支持断开及重新指定父节点。每个节点至多一个父节点；拒绝环路。
- 删除可保留子树（自动接到父节点），也可删除整枝；支持撤销、重做。
- 存储图结构和原生会话映射；原始 DSH 记录保持可恢复。路径变更生成新的上下文快照，不改写旧日志。

## 分层

1. `src/core`：纯图模型、版本验证、事务及路径计算；不依赖 DSH。
2. `src/host`：官方 `sessionQuery`、`Session`、`agents`、`agentPresets` 和 Workspace 接口的适配与上下文组装；使用原生消息事件，不增加卸载后无法解读的事件类型。
3. `src/client`：官方 Slot、SidebarRight 扩展；复用 Host React 单例与主题 token。图画布独立于宿主 DOM；消息定位适配器集中检查语义 data 属性，不覆盖内部函数。
4. `scripts`：可重复安装、备份、卸载、兼容检查；安装在用户 profile，不修改 app.asar。

## 验证

- 图操作：环路、断链、删除及重接、撤销、并发版本冲突、导入验证。
- 用真实 DSH Session 重放上下文，验证 1-2-3-4 变成 1-3-4，工具调用配对、持久化恢复。
- 在隔离 Host 验证加载、HTTP 路由、原生 UI 插件注册和实际操作。
- 最后安装至用户 desktop profile，检查资源及启用配置；用户重启后加载。

## 兼容策略

公开服务及注册点集中适配，能力检查失败时停止相关写入并报告具体原因。声明已测试版本范围；后续小版本用契约测试验证后扩大范围。无法承诺任何未来版本无需适配。
