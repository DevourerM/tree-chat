## 复现入口

```powershell
npm run build
npm test
npm run check:host
npm run pack:plugin
node scripts/install-smoke.mjs
```

`check:host` 需要通过 `DSH_DEV_RUNTIME` 指向目标 DSH 的已解包 `node_modules`。GUI 测试脚本位于 `scripts/ui-*.mjs`，需要独立 Playwright、Chromium 和隔离 Host。`TREE_CHROMIUM` 指定测试浏览器路径，命令行参数为隔离 Host 的认证 URL。测试中保留的截图在 `artifacts`，不随插件发布。

当前发布包的大小与校验信息见 `dist/checksums.json`。公开发行位于 [GitHub Releases](https://github.com/DevourerM/tree-chat/releases)，未发布到 npm。
