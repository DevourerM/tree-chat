# 0.2.1 发布审核

审核日期：2026-10-16。目标：Windows / DeepSeek Harness 0.2.0-rc.2。

按维护者要求，使用 web-agent-collaboration 工作流把当前插件源码和发布约束交给 Gemini 网页中实际显示的 **Argon** 审核；页面未显示独立的推理档位，本记录不推断具体档位。主代理负责对审核建议复核、应用、执行本地验证及发布。审核模型无法直接执行本机测试。

## 审核范围

- 图模型、上下文重建、会话映射与原子存储。
- 选中与跳转、布局缓存、待输入分支、删除后桥接与撤销。
- 原生归档收纳、分枝恢复和后台轮询。
- DSH 标准插件清单、预构建文件、发行包与 GitHub 安装入口。
- 本地多插件工作区迁移后的开发脚本、独立仓库可移植性和验证方法。

## 采纳并复核的改动

1. **后台同步与待输入状态分开。** 轮询未激活分支的完成轮次不改变当前图的活动位置。内部轮次单独完成时保留待输入节点及其布局，只有真实用户轮次结束后才转正并继承位置。
2. **删除后的选择缓存同步更新。** 删除、撤销或切换派生会话时，缓存使用有效的新节点，避免短暂恢复已删除的选中项。
3. **分支归档恢复。** 对同树中明确请求的切换或派生操作恢复目标会话，消除来源会话已归档时的不必要拒绝；用户置顶的会话继续豁免自动归档。
4. **开发工具可移植。** 测试脚本统一通过环境变量和目录探测寻找宿主运行时、Playwright 与产物目录。安装辅助工具使用显式的宿主安装路径，不将作者电脑路径作为运行依赖。
5. **发行入口独立。** 公开仓库根包含插件 `package.json` 和预构建 `lib/`，而非本地多插件工作区根清单；采用固定版本 `.tgz` 地址和 Git 标签，保留现有许可证署名。
6. **待输入分支返回与视野。** 返回已被归档收纳的待输入会话时，先通过 Host 复用并恢复它，再聚焦输入框；显式创建或继续分枝时，仅在目标节点越界时按原缩放微调画布平移，使窄侧栏中的新节点可见。

审核中新增的测试也经过本机复核：手写会话夹具不能替代宿主对继承前缀的校验；同样，保留挂载的隐藏侧栏不能计入当前可见树的 GUI 断言。验证使用原生 Session 和可见面板，未以放宽产品校验的方式使测试通过。

## 保留的限制

- 仅声明实际验证的宿主版本与系统，不保证未来 API 无需适配。
- 宿主已压缩替代或工具配对不完整的路径会被拒绝重建，原始会话保留。
- 不自动合并历史原生 fork；导出树 JSON 不能替代原生会话备份。
- 没有发布 npm 包。标准安装入口为 GitHub Release `.tgz`，Git 地址和本机绝对路径可作替代。

原始网页请求、回复、机器路径与执行日志保存在维护者本地交接目录，不随公共仓库和插件包分发。实际执行结果见 [验证记录](VALIDATION.md)。
